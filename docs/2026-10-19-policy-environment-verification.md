# 정책효과와 환경 성과 검증 결과

2026-10-19. 검증 범위는 공식 업무보고의 성과 수치 확인, 실제 2025년 기록의 배차 단계 단축 민감도, 환경 성과의 자료·비교 경계 확인이다. **이번 제안의 실제 정책 인과효과와 순탄소 감축량은 식별하지 못했다.** 미확인을 0효과나 감축 실패로 해석하지 않는다.

## 1 공식 보고에서 확인한 성과

서울시 2026년 2월 교통실 업무보고 PDF 8쪽에는 장애인콜택시 대기시간이 2023년 47.0분, 2024년 40.8분, 2025년 33.8분으로 기재돼 있다. 2024~2025년 변화는 7.0분·17.16% 감소다. 원문을 pdftotext로 읽어 수치를 추출했고 파일 해시를 기록했다.

이는 여러 운영·차량 정책이 함께 시행된 서울시 전체의 행정 보고값이다. 주 분석의 치료·재활 집합과 동일한 모집단·대기시간 정의라고 검증하지 않았다. 이번 제안 또는 특정 DRT·운전원 증원의 인과효과로 귀속할 수 없다. 2025년 4월 투입과 5월 증차를 언급한 기존 업무보고도 향후계획 성격이어서 실제 시행·노출 자료를 대신하지 못한다.

## 2 실제 기록에서 계산한 개선 목표의 민감도

기존 주 분석 6,683건을 고정하고 월~금(공휴일 포함) 예정시각 07:00~09:59의 2,992건에 한해 접수→배차 간격을 최대 0·5·10·15·20분 단축한다고 가정했다. 실제 간격이 가정 단축분보다 짧으면 해당 간격만 줄여 0 미만이 되지 않게 했다. 배차→승차·운행·다른 요청·접수 시각은 바꾸지 않았다.

| 가정한 최대 단축 | 대상 오전 60분 초과 비율 | 전체 주 분석 60분 초과 건수 | 조건부로 기준을 벗어난 기록 |
|---|---:|---:|---:|
| 0분 | 38.27% | 1,374건 | 0건 |
| 5분 | 31.12% | 1,160건 | 214건 |
| 10분 | 25.30% | 986건 | 388건 |
| 15분 | 20.29% | 836건 | 538건 |
| 20분 | 15.21% | 684건 | 690건 |

10분 가정에서는 전체 초과 비율이 20.56%에서 14.75%, 전체 P90은 76.72분에서 68.56분으로 계산됐다. 별도 CSV·datetime 원자료 재계산에서도 1,374→986건, 기준을 벗어난 388건, 대상 오전 초과 757건이 일치했다. 이 기록들은 고유 이용자 수가 아니다.

이는 고정된 기록의 산술 민감도다. 차량·근무표·배차 순서·차고지·교통 혼잡과 요청 간 경쟁을 재현한 운행 또는 대기행렬 모형이 아니며, 10분 단축을 실제 달성할 수 있다는 증거가 아니다. 줄어든 대기 분을 차량 가동시간·인건비·연료 절감량으로 환산하지 않는다. 배차 전 간격을 0으로 놓은 상한도 현실적 계획으로 사용하지 않는다.

## 3 환경 성과 판정

현재 공개·로컬 자료에 실제 도입 전후 총주행·공차·회송거리, 연료·전력 사용량, 자가용 대체와 기존 서비스 회피 배출의 완전한 비교 기준선이 없다. 2025년 기록으로 2026년 공급 보강 이후 성과를 검증할 수 없다. 예제 측정 자료는 SYNTHETIC 시나리오이며 실적이 아니다.

기존 세 설명용 자가용 대체 계산에서는 순배출이 각각 14.27t 증가, 3.74t 증가, 0.95t 감소였다. 가정에 따라 부호가 바뀌므로 일관된 순감축을 지지하지 않는다. 이 범위는 확률 예측이나 신뢰구간도 아니다. 과거 간이 배출계수와 미검증 연비의 산술 검증을 실제 환경 성과 검증으로 바꾸지 않았다.

따라서 실제 정책효과 분·실제 순탄소 감축량은 모두 null로 저장한다. 실제 에너지 자료를 입력한 회계 계산도 자가용 대체의 인과관계·지원 수준·비교 타당성을 자동 인증하지 않도록 했다.

## 4 다음 실증에서 통과해야 할 기준

- 실제 시행일·대상과 비교집합을 확정하고, 정책 이전 추세와 계절·요일·지원 요구를 확인한다. 기존 전체 평균 변화만으로 인과성을 인정하지 않는다.
- 완료·미수용·취소·희망 도착·복귀와 비대상 이용자의 부담을 포함해 정책 효과를 평가한다. 완료 기록만 좋아지는 선택효과를 점검한다.
- 실제 차량별 총운행·공차거리 및 주유·충전량을 같은 경계로 집계한다. 기존 서비스와 자가용 회피를 빠짐없이 포함하고 중복 계상하지 않는다.
- 지원·안전·도착 조건과 자원 제약을 충족하며, 비교 가능한 결과에서 시간 부담 개선과 환경 회계를 확인한 뒤 성과로 판단한다.
