# 심사위원 관점에서 본 근거와 수상 경쟁력 검토

2026-10-19. 아래 평가는 공개된 공모 목적과 실제 분석·코드·보고서를 대조한 검토 의견이다. 공식 세부 배점과 경쟁작 수준을 확인하지 못해 점수·수상 확률을 제시하지 않는다.

## 핵심 판정

실제 이동지원 기록의 시간 부담 분석은 제출물의 강점이다. 반면 약 0.95tCO2eq는 현재 정책의 가장 그럴듯한 예상 감축량으로 지지할 근거가 없다. 숫자를 계산하는 코드와 테스트를 추가해도 자가용 대체율·합승·공차·우회·연비의 근거가 생기는 것은 아니다. 본문에서 예측치로 앞세우면 제출물 전체의 신뢰도를 해칠 수 있다는 것이 검토 의견이다.

사용자의 이전 요청에 따라 조건부 추정값을 본문에 넣었으나, 심사 관점의 권고는 0.95톤을 기대효과의 대표 숫자로 사용하지 않고 공개 코드·보조 문서의 설명용 시나리오로 남기는 것이다. 후속 수정에서 0.95톤은 본문의 예상 성과에서 제외하고 설명용 보조 시나리오로 분리했다. 선행연구와의 차이 및 채택·확대·중단 기준도 제출본에 반영했다.

## 탄소 가정의 근거

| 가정 또는 수치 | 근거 상태 | 심사자가 확인할 질문 |
|---|---|---|
| 42,536.795km | 주 분석의 실제 승차거리 합계, 다른 구현 재계산 일치 | 기존 콜택시 기록을 왜 신규 DRT 규모로 옮겼는가 |
| 자가용 대체 거리 비중 70% | 설명용 설정, 서울 대상 실측·추정 없음 | 왜 30%나 10%가 아닌가 |
| 거리 가중 평균 대상 이용자 3명 | 설명용 설정, 지원·공간·동시 수송 검증 없음 | 휠체어 공간과 승하차·도착 제약에서 실현 가능한가 |
| 공차/승차거리 비율 10% | 설명용 설정, GPS·공차 자료 없음 | 실제 배차·회송을 어디서 측정했는가 |
| 추가 우회율 10% | 설명용 설정, 운행 재현·제약 검증 없음 | 치료 도착시각과 합승 경로가 가능한가 |
| 자가용 12km/L·DRT 10km/L | 설명용 설정, 차량·연료 구성 확인 안 됨 | 대상 차종·운행 조건에서 확인한 값인가 |
| 배출계수 2.18·2.6 | 공식 과거 생활 실천 안내서에 근거 | 현재 차량 인벤토리에 맞는 범위와 계수인가 |
| 0.95t 감소 | 설정값을 대입한 계산 결과 | 왜 증가 사례가 아닌 이 사례를 대표값으로 골랐는가 |

설명용 세 사례는 대체율·재차인원·공차를 동시에 바꾼다. 결과 차이는 특정 변수 하나의 효과가 아니다. 108개 조합도 실현 가능한 운영 분포나 성공 확률을 뜻하지 않는다. 출처가 있는 배출계수는 나머지 가정의 타당성을 보증하지 않는다.

## 더 근본적인 비교 경계 문제

보고서의 핵심 대상은 기존 장애인콜택시 치료·재활 완료 기록이다. 탄소 모형은 같은 규모의 가상 신규 서비스 전체 배출에서 일부 자가용 회피 배출만 차감한다. 두 질문의 기준선이 다르다. 이 모형으로 기존 배차 개선 정책의 순탄소 효과를 추정할 수 없다. 조건부라고 표시해도 정책 대상과 비교 경계가 맞는지의 문제는 남는다.

## 전체 보고서의 경쟁력

| 영역 | 현재 평가와 보완 방향 |
|---|---|
| 공모 목적 | 필수 목적 이동의 부담·형평성은 공식 목적에 부합한다. 탄소 감축량을 만들어 맞출 필요는 없다. |
| 원자료·재현성 | 연간 원자료, 시간·목적 조건, 월별 확인, 별도 집계 검증과 코드 공개는 강점이다. 원본 행 수 자체보다 선별 조건과 결론의 연결을 설명해야 한다. |
| 문제 진단 | 6,683건 중 20.56%, 장시간 기록의 오전 집중과 배차 전후 분해는 구체적이다. 목적 불명 80.77%와 완료 기록 선택 때문에 서울 전체 치료·재활 접근으로 일반화하지 않는다. |
| 대상 선정 | 세 구는 탐색 사례이며 전체 서울 최우선 지역으로 선정한 것이 아니다. 지역 선정 이유를 보완하거나 사례 분석 범위를 제목·결론에서 일관되게 유지한다. |
| 차별성 | 장애인콜택시 오전 부담·재배치 자체는 선행연구와 기존 정책에도 있다. 목적·시간대·지원 조건별 검증과 대안 선택 기준을 기여로 좁혀야 한다. |
| 정책 효과 | 기존 운영 개선을 우선 검증한다는 판단은 가능하지만 실제 대기 감소 효과나 우월성을 입증한 결과는 없다. 제안과 검증 결과를 구분한다. |
| 비용 | 기준 가정에서 비용 우위를 확인하지 못한 결과를 남긴 것은 신뢰성에 도움이 된다. 과거 평균비용은 현재 동일 지원 서비스의 추가 견적과 다르다. |
| 예산 | 제출안 대비 0.11%는 규모 비교이지 확보된 재원·의결액·집행 잔액이 아니다. 이를 실행 가능성의 증명으로 사용하지 않는다. |
| AI | 실제 활용 범위와 검증을 제시한 점은 적절하다. AI 코드 작성·규칙 점검을 배차 최적화나 예측모형 성과로 확대하지 않는다. 공모 목적만으로 학습모형이 필수라고 단정하지 않는다. |
| 환경 | 현재 가장 약한 근거다. 예상 감축량 대신 공차·에너지·지원 수준을 함께 점검하는 운영 평가 기준과 감축 손익분기 분석으로 제시하는 편이 낫다. |

## 우선순위

1. 0.95톤을 대표 기대효과에서 내려 놓고 설명용 시나리오로 구분한다. 긍정·부정 사례를 함께 유지하고 가정 근거표를 공개한다.
2. 치료·재활 기록의 시간 부담이라는 실제 관측과 그에 대응하는 오전 배차 단계 점검을 본문의 중심으로 유지한다.
3. 기존 정책·선행연구와의 차이를 명시하고 독창성을 최초 발견이나 새로운 DRT 명칭에서 찾지 않는다.
4. 지원 수준·도착 제약·운영 자원을 확인하지 않은 합승·차량 수는 확정 정책안으로 쓰지 않는다.
5. 남은 분석을 한다면 새로운 가정 수를 늘리기보다 취소·목적 불명·구별 구성 차이·이미 보강된 공급 등 결론을 반박할 자료를 검토한다. 이미 사용한 전체 기간을 새로 떼어 진정한 미사용 검증집합이라고 부르지 않는다.

## 심사 질의에 대한 답변 방향

“탄소 감축을 실증했습니까?”에는 “아닙니다. 실제 승차거리 기준선과 조건부 계산을 제시했으며 대체율·에너지·공차는 후속 검증 대상입니다”라고 답한다. “왜 DRT입니까?”에는 “필수 도입 결론이 아니라 기존 운영 개선 이후 추가 성과를 검증할 대안입니다”라고 답한다. 이 답변이 불리해 보인다고 입증되지 않은 효과로 바꾸지 않는다.

표현을 다듬는 것보다 관측·가정·제안의 경계를 맞추는 것이 심사 대응력을 높일 가능성이 크다. 다만 이러한 개선이 수상을 보장하거나 특정 확률로 높인다고 판단할 근거는 없다.
